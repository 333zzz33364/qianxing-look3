# 【未读】本机字体设置

- 【未读】在 Look2 编辑器顶部选择“字体设置”，可选择自动查找、指定 TTF/OTF 文件或系统字体。
- 【未读】自动查找只检查设置面板列出的少量游戏默认目录；安装位置不同可手动指定字体文件。单个字体最大 32 MiB。
- 【未读】应用范围可选“仅游戏内文本”或“整体 UI”；整体 UI 会同时替换 Look2 工具界面字体。
- 【未读】设置保存在用户配置目录下的 `千星look3/font.json`，与工程存档和分发包分离。`QXQY_FONT_CONFIG_PATH` 可用于隔离配置；`QXQY_FONT_PATH` 环境变量优先固定字体来源。
- 【未读】保存后需重启 Web、MCP 或 DSH 宿主，并刷新编辑器和试玩页。字体文件移动或失效时，可打开面板改选系统字体或新文件恢复。
- 【未读】字体设置接口只允许直接 loopback 请求；Web 仍受现有认证保护，跨来源及代理转发请求会被拒绝。
