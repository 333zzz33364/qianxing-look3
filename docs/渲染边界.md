# 【未读】图片与遮罩的渲染边界

【未读】Authoring 保存一份图片、填充和遮罩参数。作者画面、Pixi 播放和 PNG 导出共用几何语义，通过各自的资源与绘图适配器显示；它们不维护第二份可编辑工程状态。

| 【未读】入口 | 遮罩覆盖规则 | 资源职责 |
| --- | --- | --- |
| 【未读】作者画面 | 图片源纹理透明度与遮罩几何共同决定覆盖范围 | 编辑器负责加载图片并显示作者预览 |
| 【未读】Pixi 播放 | 使用控件矩形及填充、软边、反转等几何参数；图片透明轮廓不追加为后代遮罩 | 播放渲染器负责图片纹理与显示对象生命周期 |
| 【未读】PNG 与平面回退 | 沿用播放的几何遮罩规则 | 宿主负责资源解析、离屏绘制与截图 |

【未读】透明轮廓的两种规则按用户选择保留，属于明确的预览差异。图片本身的透明像素仍参与图片绘制；这里的差异指该图片作为遮罩时如何裁剪后代。真实透明图片的千星表现需由目标编辑器与游戏分别验证，现有不透明代理样本不能证明该规则。

【未读】软边共有两种组合契约：Pixel 模式沿用旧 Runtime 的双轴最小覆盖率；Percentage 模式将水平、垂直覆盖率相乘。作者画面、Pixi 和 PNG 在几何层保持这两种契约。禁用软边时不应由平面回退重新引入羽化。

【未读】径向填充支持 90°、180°、360°及方向参数；反转遮罩与父子遮罩组合属于几何与坐标适配职责。JSON/GIA 的字段保留、作者画面的效果、播放截图和千星实机效果是不同的证据层，任何一层通过都不自动证明其他层。

【未读】实现入口为 `editor-ui/stage-image-mask.js`、`studio/play/image-geometry.js`、`studio/play/image-mask.js`、`studio/play/pixi-renderer.js` 和 `studio/host-png.js`。资源生命周期与宿主共享边界见 [Studio](../studio/README.md) 和[分发设计](../DISTRIBUTION.md)。
