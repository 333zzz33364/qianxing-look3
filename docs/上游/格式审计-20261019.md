## 【未读】清单逐项核对

### 【未读】U-IM01：站点 JSON v12、旧世界布局和字段往返

【未读】**来源：** 固定 UGC 的 `ClientUIAnimationEditor.vue`：`makeNode` 默认世界坐标取画布常量中心；`normalizeNode` 在缺少四个保存布局字段时，以 `canvasWidth / 2 + x`、`canvasHeight / 2 - y` 生成旧世界坐标；`migrateLegacyHierarchyLayout` 在非层级布局 v2 时，将旧世界点经父级旋转/缩放逆矩阵转为父局部坐标，再加父 pivot；`serializeProject` 写 v12、`hierarchyLayoutVersion: 2`、`controlModelVersion: 2`、`timelineModelVersion: 10`。

【未读】**本地已验证：** [site-json.js](../../studio/look2/site-json.js) 对带旧 `x/y` 的非 v2 工程执行树级迁移；缺少布局状态的行按输入画布中心和 Y 反向语义归一化，完整布局状态却缺 `x/y` 的行按上游固定默认点 `(800, 450)` 处理。父级逆变换、非中心 pivot 和尺寸锚点回算均由[旧布局几何测试](../../studio/test/look3-site-interop.test.mjs)覆盖：一项检查旋转/缩放父级并验证 v2 本地坐标导出及重开稳定；新增混合行测试覆盖 1280×800 自定义画布、一个有旧 `x/y` 行触发整树迁移、缺 `x/y` 的完整布局行、`中心 - y`、非中心父 pivot，并检查四个平台槽的结果。导出固定写 v2/v2/v10。

【未读】**仍缺：** 本地为兼容缺少 `x/y` 的 Look2 变换式输入，仅在任一行存在有限旧 `x` 或 `y` 时迁移；固定 UGC 源码则对所有非 v2 文档无条件调用迁移。缺 marker 且整份 JSON 都没有 `x/y` 的外部旧档语义尚无真实样本确认，当前保护旧 Look2 数据的分支因此记作有意兼容差异，不能宣称对这类外部档完全等价。尚未用 UGC 网页编辑器或目标程序导入验收。

### 【未读】U-AN05、U-LU01：Clip v4–v6 坐标、入侧值和多文本动画

【未读】**来源：** `ClientUIAnimationEditor.vue` 的 `normalizeTweenTracks` 只转换 v4 绝对坐标和 v6 父级中心偏移；v5 与其他已是锚点偏移的值保持。`keyframeTimeline.ts` 将前一有效帧右值作为后续相对值基准，并以 `incomingValue` / `incomingRelative` 表达该关键帧的入侧值。

【未读】**本地已验证：** [旧 Clip 适配](../../studio/look2/site-legacy.js)按 v4/v6 转换位置，按 v4 转换实际尺寸到 `sizeDelta`，v5 保留原锚点坐标；[Clip 回归](../../studio/test/look3-site-interop.test.mjs)分别断言 v4/v5/v6 位置和大小值，另用旋转、非等比缩放父级检查 v4 绝对 X 的轴向换算。[字段适配](../../studio/look2/site-fields.js)在站点格式与内部 `leftValue` / `leftRelative` 间双向转换。入侧值测试检查采样中点、编辑后写回 `incomingValue`、保留事件与未知字段，且不修改输入对象；多文本用例在生成的 player Lua 和 Timeline 库两条路径中同时驱动两个文本控件及遮罩羽化轨道，分别得到预期值。`look2-animation-interop.test.mjs` 另覆盖相对位置/大小/缩放、入侧相对值和 Timeline Data v3–v7 导入。

【未读】**仍缺：** Clip v4/v5/v6 和 incoming 目前由按固定源码行为构造的本地 fixture 验证，没有对应年代的真实 UGC 导出档案；UGC 编辑器、真实 GIA/TimelineData 目标端播放验收仍待做。

### 【未读】U-TP01：四设备模板 GIA、索引和实例化

【未读】**来源：** UGC `giaImporter.ts` 的 `importGiaControlTemplate` 对设备索引 0–3 各读一次；`controlTemplates.ts` 要求模板恰有四个非空设备树、唯一索引及有效布局，并保留名称、来源和警告。

【未读】**本地已验证：** [模板适配](../../studio/look2/site-templates.js)保留原始 `devices` 数组与未知字段，分别建立四个平台变换；[四设备 JSON 模板测试](../../studio/test/look3-site-interop.test.mjs)验证各设备不同偏移 `[0, 10, 20, 30]`、仅触屏设备的文本差异、子节点顺序、保存重开、实例化与导出回读。[模板历史测试](../../studio/test/look2-history.test.mjs)覆盖 GIA 模板导入、索引冲突、保存重开、引用缺失提示、脚本保留和重复实例化；[平台布局测试](../../studio/test/platform-layout.test.mjs)验证四个平台不同布局经 JSON、普通 GIA 和 combined GIA 往返不丢失。

【未读】本阶段补上工作台作者层预览：`projectPreviewTreeForPlatform()` 按所选平台从 `transformByPlatform` 生成临时预览树，四个平台使用同一套五种几何画布尺寸；平台按钮不再写 `canvasId`，画布尺寸仍由独立的尺寸选择器控制。键鼠/触屏拖动和坐标提交、骨骼创建/附着源码均使用作者预览平台；控制器槽位可显示并通过对应控件节点的点击处理器选择控件，状态明确标注这是“控制器槽位预览，不代表手柄运行时”。[作者预览组件函数测试](../../studio/test/editor-platform-preview.test.mjs)检查四槽位置、视口不变、触屏 gizmo、控制器节点选择及存档/运行时编译树不变，1/1 通过；它未实际驱动拖动/坐标提交或浏览器指针事件。此测试使用 fake React hook 渲染器调用真实 `AnimationView` 组件函数，不是浏览器测试。

【未读】**仍缺：** 上述四设备专用 fixture 是站点 JSON 模型；模板 GIA 测试使用本地生成的 GIA 或独立观察的常规 GIA fixture，尚无固定 UGC 工具实际产出的四设备模板 GIA 字节样本做端到端回导。作者层预览选择是编辑会话内状态，不写入工程存档，重开默认键鼠。真实 UGC 导入与外部实例化验收待做；控制器槽位作者预览不证明目标运行时支持手柄输入或控制器运行时行为。

### 【未读】U-UI08：遮罩、羽化、填充字段及旧 GIA 遮罩恢复

【未读】**来源：** UGC `controlRegistry.ts` 定义 `enableMask`、`enableSoftEdge`、软边模式/宽度、水平/垂直范围、`reverseMaskArea` 和填充字段；`giaImporter.ts` / `giaExporter.ts` 使用图像配置字段 501、509–516 读写遮罩、羽化、范围、填充和反转；`SpriteImage.vue` 与 `imageFeatherPreview.ts` 实现作者预览中的反转、百分比范围及径向填充。

【未读】**本地已验证：** Site JSON 测试逐字段往返软边模式/宽度、范围、反转和填充设置；[旧 GIA mask 迁移](../../studio/look2/site-gia.js)仅从旧 `giaSource` 恢复遮罩开关并记录 `imageMaskVersion`，回归检查未改输入、保留原始文档，并在用户有意关闭开关时不覆盖。`upstream-core-integration.test.mjs` 通过实际 GIA wire roundtrip 检查分数范围、反转及填充方向；`editor-image-preview.test.mjs` 的 11 项检查覆盖遮罩反转、像素/百分比羽化、填充方向和径向预览。

【未读】**仍缺：** Studio 播放渲染与 UGC 作者预览语义不完全一致：`studio/play/image-mask.js` 明确未应用 `reverseMaskArea`，其百分比模式使用宽度值并忽略 `horizontalSoftRange` / `verticalSoftRange`；`studio/play/image-fill.js` 未实现径向填充。`look2-image-mask.test.mjs` 只证明矩形后代裁切和像素羽化，不能证明这些未支持模式。字段在 JSON/GIA 中保存不等于 Runtime 行为等价；此缺口需单独排期，且当前审计范围不包含 `studio/play/`。
