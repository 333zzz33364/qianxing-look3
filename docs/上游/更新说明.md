# 千星look3 上游维护

1. 【未读】**来源与状态分开。** `来源.json` 记录固定参考版本及已接受版本；`功能清单.json` 记录62项功能的实现、源码和验收。固定源码在 `上游/Look` 与 `上游/UI动画编辑器`，不随运行包分发。
2. 【未读】**检查。** 运行 `pnpm upstream:check`，仅抓取参考仓库对象并输出变更文件/受影响功能；不切换固定检出、不修改业务源码、不改变接受状态。`--offline` 不访问网络。可用 `--output look3-workspace/更新/报告.json` 保存报告。
3. 【未读】**适配。** 按功能比较当前实现与上游变化，保留本地界面、动画、多GIA与已确认修复；在本地Git分支上实现并审阅差异。Vue页面不直接替换React/Studio；上游较窄的格式能力不能覆盖本地已支持范围。
4. 【未读】**应用。** 已审阅的适配补丁放入项目内，再运行 `node scripts/upstream-sync.mjs apply --patch <路径>`。先做原子预检，失败不部分写入；禁止补丁改写用户工作区、参考仓库、Git元数据、发布包及来源/验收记录。命令不会自动提交或前移接受版本。
5. 【未读】**验证与接受。** 每批做相关局部验证；公共变更与交付前运行 `pnpm test`、`pnpm build`、`pnpm pack:release`、`pnpm test:packages`。涉及源码安装入口时另跑 `pnpm test:git-install`。对照逐项证据后再在审阅的提交中更新来源接受版本和功能状态。
6. 【未读】**恢复。** 本地Git保留整合前基线和阶段提交。恢复源码前先保存用户当前改动；用户存档/参考仓库/构建证据不随源码恢复。原Look2仍位于同级目录，旧包与旧证据不得标为新版本结果。
7. 【未读】**范围限制。** 上游不支持的官方能力仍明确列为上游限制；本地代码、浏览器、独立安装、真实宿主与千星实机证据分开。字体只使用用户自行提供的授权本地字体，不捆绑上游引用的字体文件。
