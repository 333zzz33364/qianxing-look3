## 【未读】3. 第二批：补齐作者预览与播放渲染差异（核心缺口）

3.1 【未读】补齐径向90°/180°/360°填充、起始方向与顺逆时针；参考2号已有作者算法，统一字段解释和几何计算。覆盖0、1及中间进度、旋转/缩放和不同长宽比。

3.2 【未读】补齐反转遮罩，明确矩形内外区域、父子继承和嵌套遮罩组合；不能只翻转一张截图或只修改编辑器CSS。

3.3 【未读】补齐百分比软边，统一水平/垂直范围、像素模式和百分比模式的换算；验证不同尺寸、缩放与嵌套场景。

3.4 【未读】【影响范围】共享几何/遮罩辅助逻辑、作者预览、`studio/play/`和PNG/宿主截图路径、Web/DSH播放接线及相关测试。保持一份Authoring权威数据，通过适配进入各渲染入口。

3.5 【未读】【本批完成条件】同一工程在作者画面、Web/DSH播放及实际PNG/截图链路按相同参数得到可解释的一致结果；JSON/GIA往返不丢字段，旧水平/垂直填充和像素软边保持。千星最终效果在阶段6另验，不能由本地截图替代。

3.6 【未读】【兼容差异单列】Timeline无效/未来版本的错误出口、Primitive公开返回数组、旧缓动别名继续保留并明确记录；不把有意兼容差异当成必须复制上游的缺陷。KeyHint等未核实原生语义不猜测编码，控制器槽位预览不等于手柄Runtime支持。
